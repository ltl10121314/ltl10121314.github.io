Colima、Docker、Docker Compose、Linux 常用命令

系统与中间件 / Docker 阅读约 17 分钟访问量—次

在 Mac 上使用 Colima + Docker + Docker
Compose，建议把常用命令分成四个层次来学习：

  1. Colima：管理 Mac 上的 Linux 虚拟机。
  2. Docker：管理容器、镜像、网络、数据卷。
  3. Docker Compose：管理多个容器组成的应用。
  4. Linux：进入容器或虚拟机后，管理文件、进程、网络、权限和服务。

Docker 常用命令

Docker 主要管理四种资源：

  • Image：镜像，相当于容器的模板。
  • Container：容器，镜像运行后的实例。
  • Network：容器网络。
  • Volume：数据卷，持久化存储数据。

建议的学习顺序

结合 Kafka、Nacos、Spring Boot 技术栈，建议按下面顺序学习：

  1. Colima：理解 Mac 如何运行 Linux 虚拟机。
  2. Docker：理解镜像、容器、网络、数据卷。
  3. Docker Compose：学会部署 Kafka、Redis、MySQL、Nacos。
  4. Linux：理解进程、端口、网络、文件权限、日志。
  5. Docker 网络：理解容器之间如何通过服务名通信。
  6. Linux 排错：掌握 DNS、端口占用、磁盘、内存和进程排查。

核心区别：

  • Colima 管理本机 Linux 虚拟机。
  • Docker 管理容器和镜像等资源。
  • Docker Compose 管理一组有关联的容器服务。
  • Linux 命令用于管理虚拟机或容器内部的操作系统环境。

下一步可以基于现有的 ~/docker/backend/，从 Mac 终端启动 Colima，使用
Docker Compose 部署 Kafka、Redis、MySQL，再进入 Linux
容器排查端口、DNS、日志、进程和磁盘问题。这样能把四类命令串成一套完整的后端开发运维技能。
